# Ảnh chụp màn hình

Ảnh được chụp khi chạy các view với dữ liệu mẫu cùng cấu trúc với bảng hợp đồng API, vì backend chưa hoàn thiện lúc chụp. Khi backend xong, chụp lại bằng dữ liệu thật để đưa vào báo cáo.

| Ảnh | Màn hình |
|---|---|
| 01 | Đăng nhập |
| 02 | Đăng ký |
| 03 | Đăng dự án |
| 04 | Dự án của tôi |
| 05 | Chi tiết dự án (chủ dự án) |
| 06 | Sửa dự án |
| 07 | Hộp thoại xác nhận |
| 08 | Tìm dự án |
| 09 | Gửi đề xuất |
| 10 | Đề xuất của tôi |
| 11 | Sửa đề xuất |
| 12 | Hồ sơ |
| 13 | Đánh giá bằng sao |
| 14 | Trang lỗi 404 |
| 15 đến 17 | Bản điện thoại (360px) |
